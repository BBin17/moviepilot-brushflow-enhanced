# 站点刷流

站点刷流 8.0 使用 Vue 模块联邦提供任务工作台。每项任务独立绑定一个站点和一个下载器，并拥有自己的调度周期、容量闭环、本地收益模型、选删种审计和运行诊断。

全局设置支持限制所有任务合计的保种体积、同时下载任务数和总上传下载带宽；任务编辑器中的运行限额仍只约束当前任务。限额留空或设置为 `0` 表示不限制。

7.3.0 新增站点自动签到：在全局设置中启用后，按 5 位 CRON 计划串行访问已保存站点 Cookie 对应的 `attendance.php`。默认使用启用刷流任务绑定的站点，也可以手动选择站点。当天成功或已签到的站点会跳过，失败站点在下一次计划重试，结果保留 31 天并可发送通知。需要答题、验证码或专用 API 的站点只会安全报告不支持，不会盲目提交。

8.0 智能模式使用任务级 30 天本地收益学习。Tracker 人数未知时保持中性；下载者在最近 3 次检查中至少出现 2 次才算可信，任何新上传增量立即保护。删除候选必须连续低价值、满足确认跨度和闲置时间，并受未完成、H&R、站点最低保种、排除标签、真实上传与活动连接硬安全线保护。均衡容量在 90% 触发、85% 停止，每轮和每天同时受数量与 GB 双限额。

8.0.2 修复智能选种放宽模式绕过明确大小限制的问题：填写 `0.5` 表示最低 0.5 GB，填写 `0.5-2` 表示闭区间；大小始终是硬过滤，只有做种人数范围可以交给智能评分。8.0.1 增加下载健康观测：读取 qBittorrent 的已完成字节、实时下载速度和下载器状态，以连续采样区分“长时间无进度”和“有增量但异常低速”。

启用“自动清理无效做种”后，插件参考清理无效做种插件的 Tracker 错误判定，只处理明确的 `torrent not registered`、`torrent banned`、`torrent not exists` 等拒绝消息；会先确认同一 Tracker 在其它种子上仍正常，再按连续确认次数执行。执行时只移除 qBittorrent 任务，不删除下载数据，避免站点临时故障和跨站辅种误删。

智能选种由促销、可信需求、可信稀缺性、新鲜度、本地历史收益、单位容量效率和动态容量成本组成。分享率未达标时最多放宽 5 分；达到目标后恢复普通门槛但继续运行。均衡预设下，大于 50 GB 且没有可信需求的候选直接跳过。

全局动态删种会汇总所有启用任务的做种体积。单值阈值（如 `100`）在达到 100 GB 后删到 100 GB；区间阈值（如 `50-100`）在达到 100 GB 后删到 50 GB。任务启用动态删种时，其已完成非 H&R 种子会参加全局兜底淘汰；未启用的任务只会在全局阈值触发后按自身删种条件处理。关闭全局模式时，没有独立动态删种阈值的参与任务会恢复为按条件删除。

任务可启用站点账号分享率控制：插件读取 MoviePilot 最新站点统计。8.0 默认在达到目标后继续按普通均衡门槛运行，也可在高级行为中切回暂停新增。

## 升级兼容

- V3 专用版本依赖 MoviePilot `v3.0.0+`，旧版宿主会在安装和更新前拒绝该版本。
- 首次加载 V5 时，旧版 `brushsites` 会按站点拆分为独立任务。
- 从 V4 直接升级时，原有运行限额和全局动态删种会迁移到新的全局设置；已升级到 V5 的用户可在全局设置中重新设置合计限额。
- 旧版站点覆盖 JSON 会合并到对应任务中。
- 原有种子、归档和未托管数据会按站点迁移到任务命名空间。
- 原来开启智能删种的任务会备份升级前配置、映射到均衡预设并进入 48 小时影子观察；原来关闭的任务不会被误启用。影子期只记录计划，误判率超过 15% 或出现硬安全违规会自动延长 24 小时。
- 已有的全局 `刷流` 标签继续识别；V5 新增任务唯一标签，避免多个任务互相接管。V6.0.1 起默认使用按站点名称生成的可读标签（如 `刷流-聆音`），同一站点存在多个任务时请在任务编辑器中设置为不同的下载器标签。
- V5.0.2 会在插件启动、任务检查和任务删除后清理 qBittorrent 中不再被任何种子使用的 `刷流-*` 标签；仍绑定种子的标签不会被强制移除。
- V5.1.0 新增站点账号分享率目标控制，并限制运行诊断长列表在模块内部滚动。
- V5.1.1 修复 YemaPT 间接下载链接只返回 token、导致刷流任务无法获取种子 Hash 的问题。
- V5.1.2 会在最近的免费促销截止时间即时检查未完成下载，同时保留周期检查兜底，并修正跨时区到期判断。
- V5.2.0 恢复 V4 的全局动态删种，并适配 V5 的多任务、多下载器和任务级托管开关。
- V5.2.1 修复同一下载器共享种子的跨任务保护，并按任务记录实际删除原因。
- V5.2.2 将详情弹窗的滚动限制在右侧工作区，固定顶部标题栏和左侧任务栏，并移除重复失效的配置切换按钮。
- V5.2.3 兼容 qBittorrent 5.2.3，修复动态删种后的未使用标签清理报缺少 `hashes` 参数。
- V6.0.1 新增种子下载标签配置：默认按站点名称生成可读标签（如 `刷流-聆音`），新增种子仅打该单一标签，不再叠加 `刷流` 全局标签和随机代码标签；同一站点存在多个任务时建议为任务设置不同的下载器标签。旧版 `刷流` 全局标签仍可被继续识别。

## 前端入口

插件构建产物暴露以下联邦组件：

| 组件 | 用途 |
| --- | --- |
| `AppPage` | 主界面侧栏中的完整刷流工作台 |
| `Page` | 插件详情弹窗 |
| `Config` | 插件配置弹窗 |
| `Dashboard` | 仪表板任务概览 |

侧栏入口由插件的 `get_sidebar_nav()` 注册，可在工作台全局设置中关闭。

## 插件 API

所有接口均使用宿主 Bearer 认证，基础路径为 `/api/v1/plugin/BrushFlow`。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/status` | 获取全局状态、任务摘要与可选站点下载器 |
| `POST` | `/settings` | 更新插件与侧栏入口开关 |
| `POST` | `/tasks` | 创建任务 |
| `GET` / `PUT` / `DELETE` | `/tasks/{task_id}` | 查询、更新或删除任务 |
| `POST` | `/tasks/{task_id}/state` | 启用或暂停任务 |
| `POST` | `/tasks/{task_id}/run` | 立即执行刷流刷新 |
| `POST` | `/tasks/{task_id}/check` | 立即执行种子检查 |
| `POST` | `/tasks/{task_id}/clear` | 清除当前任务的独立数据 |
| `POST` | `/tasks/{task_id}/strategy/activate` | 提前结束影子观察 |
| `POST` | `/tasks/{task_id}/strategy/extend` | 延长 24 小时观察 |
| `POST` | `/tasks/{task_id}/strategy/pause` / `resume` | 暂停或恢复自动删除 |
| `POST` | `/tasks/{task_id}/strategy/rollback` | 切换 7.3 兼容引擎 |
| `POST` | `/signin/run` | 立即执行一次站点签到 |

## 构建

在本目录安装依赖后执行 `npm run build`。构建会先验证 Python、`package.json` 与 `package.v3.json` 的 8.0.2 版本一致性和前端默认值，再生成 `dist/assets`。
