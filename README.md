# BrushFlow Enhanced 6.2.0

基于 MoviePilot 官方 `BrushFlow 6.1.0` 的完整增强版，保留原有多站点刷流、选种、限额、分享率控制、标签、H&R、促销和运行诊断功能。

## 新增删种能力

- `最少保种时长`：完成种子的硬安全线，未达到时任何普通或动态策略都不能删除。
- `最少未活动时间`：保护仍在上传的热门种子。
- `任一条件 / 全部条件`：可决定做种时间、分享率、上传量、平均速度和未活动时间之间的逻辑。
- `最低停止阈值 / 最高触发阈值`：例如达到 550 GB 后开始清理，降至 480 GB 时停止。
- `动态兜底也必须满足删除条件`：开启后容量超限不能绕过任务删除条件。
- `智能淘汰顺序`：支持闲置低速、做种最久、未活动最久、平均上传最低和体积最大优先。
- `模拟运行`：默认开启，只输出计划，不调用下载器删除接口。
- `删除下载数据`：可选择仅从下载器移除任务，或同时删除下载数据。

## 推荐的 PT 刷流配置

- 最少保种时长：`72` 小时
- 最少未活动时间：`360` 分钟
- 条件关系：`全部条件`
- 做种时间触发：`72` 小时
- 未活动时间触发：`360` 分钟
- 动态最低停止阈值：`480` GB
- 动态最高触发阈值：`550` GB
- 动态兜底也必须满足删除条件：开启
- 动态淘汰顺序：智能
- 删除排除标签：`H&R,MOVIEPILOT,KEEP`
- 模拟运行：先开启观察，确认日志无误后再关闭

## 升级说明

插件 ID 和配置前缀保持为 `BrushFlow`，因此可读取原 6.1.0 任务。旧版单值或 `低-高` 动态容量配置会自动转换到新字段。部署前请备份 MoviePilot 配置，并避免同时运行官方版和增强版。
