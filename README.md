# BrushFlow Enhanced 8.0.2

基于 MoviePilot 官方 `BrushFlow 6.1.0` 的完整增强版，保留原有多站点刷流、选种、限额、分享率控制、标签、H&R、促销和运行诊断功能。

## 智能决策模式

8.0.0 使用“任务级 30 天本地收益学习 + 硬安全线 + 90%→85% 容量闭环”。最低保种时间仍由每个任务按站点规则填写。升级前已经开启智能删种的任务会自动进入 48 小时影子观察，只生成计划、不实际删除；误判率过高或出现安全违规会自动延长 24 小时。

- 热门、正在上传、做种稀缺或可用性不足的种子继续保留；
- 长期无下载者、无上传、资源充足且已达到站点最低时长的冷种进入删除候选；
- 未完成、H&R、未达到最低保种时长、未达到最低未活动时间和命中排除标签的种子永不进入候选；
- 正式启用后默认删除下载器任务及数据；每轮和每天同时受数量与 GB 容量上限约束；
- 默认仅在容量压力时清理长期冷种，明确开启“主动清理”后才会在容量未满时按每日限额工作。

智能选种按促销、可信需求、可信稀缺性、新鲜度、本地历史收益、单位容量效率和动态容量成本评分。未知 Tracker 人数保持中性；达到站点目标分享率后恢复普通均衡门槛并继续运行。均衡预设会直接拒绝大于 50 GB 且没有可信需求的候选。

智能删种要求 Tracker 下载者在最近 3 次检查中至少出现 2 次才可信；任何真实上传增量立即保护。候选必须连续低价值 3 次、跨度至少 30 分钟并闲置至少 6 小时。累计分享率最多贡献 5 分，且仅在近期仍有上传时生效。

7.2.0 接入无效做种自动清理：只接受 Tracker 明确返回未注册、封禁或不存在，并要求同一 Tracker 在其它种子上仍然正常；默认连续确认 2 次后，仅移除 qBittorrent 任务，不删除下载数据，避免站点临时故障或跨站辅种被误删。

旧任务保持 6.2.0 的条件/动态删种逻辑；只有显式打开“智能决策删种”后才启用 7.0.0 引擎。

智能选种会在候选新增前按促销、下载者、做种稀缺性、新鲜度、体积和 H&R 风险重新排序，并限制每轮新增数量；原有包含/排除、重复种子、站点分享率和容量规则仍然优先。

## 原有删种能力

- `最少保种时长`：完成种子的硬安全线，未达到时任何普通或动态策略都不能删除。
- `最少未活动时间`：保护仍在上传的热门种子。
- `任一条件 / 全部条件`：可决定做种时间、分享率、上传量、平均速度和未活动时间之间的逻辑。
- `最低停止阈值 / 最高触发阈值`：例如达到 550 GB 后开始清理，降至 480 GB 时停止。
- `动态兜底也必须满足删除条件`：开启后容量超限不能绕过任务删除条件。
- `智能淘汰顺序`：支持闲置低速、做种最久、未活动最久、平均上传最低和体积最大优先。
- `模拟运行`：仅用于旧版条件/动态模式；智能模式不使用此开关，会按智能限额实际执行。
- `删除下载数据`：可选择仅从下载器移除任务，或同时删除下载数据。

## 旧版条件/动态模式的推荐配置

- 最少保种时长：`72` 小时
- 最少未活动时间：`360` 分钟
- 条件关系：`全部条件`
- 做种时间触发：`72` 小时
- 未活动时间触发：`360` 分钟
- 动态最低停止阈值：`480` GB
- 动态最高触发阈值：`550` GB
- 动态兜底也必须满足删除条件：开启
- 动态淘汰顺序：智能
- 删除排除标签：`H&R,MOVIEPILOT,KEEP`
- 模拟运行：先开启观察，确认日志无误后再关闭

## 升级说明

插件 ID 和配置前缀保持为 `BrushFlow`，因此可读取原 6.1.0 任务。旧版单值或 `低-高` 动态容量配置会自动转换到新字段。部署前请备份 MoviePilot 配置，并避免同时运行官方版和增强版。
